# Task 2 - Exploratory Data Analysis (EDA)

## Objective

The objective of this task is to perform Exploratory Data Analysis (EDA) on employee data and identify important patterns related to employee attrition.

## Dataset

The dataset contains employee information including:

- Age
- Attrition
- Business Travel
- Department
- Education
- Gender
- Job Level
- Monthly Income
- Job Satisfaction
- OverTime
- Total Working Years
- Years at Company

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Analysis Performed

The following analysis was performed:

1. Age Distribution
2. Employee Attrition Analysis
3. Department-wise Attrition
4. Gender-wise Attrition
5. Income-wise Attrition
6. Job Satisfaction Analysis
7. Job Level vs Attrition
8. Overtime vs Attrition
9. Experience vs Attrition
10. Employee Attrition Insights
