# Task 3 - Data Visualization

## Objective

The objective of this task is to transform data into meaningful visualizations and present insights using charts and graphs.

## Project

Employee Attrition Data Visualization

## Dataset

The dataset contains employee information such as:

- Age
- Gender
- Department
- Job Level
- Monthly Income
- Job Satisfaction
- Overtime
- Attrition

## Tools and Technologies

- Python
- Pandas
- Matplotlib
- Seaborn

## Visualizations

The project includes the following visualizations:

1. Attrition Distribution
2. Department-wise Attrition
3. Gender-wise Attrition
4. Age Distribution
5. Monthly Income Distribution
6. Job Satisfaction Distribution
7. Overtime vs Attrition
8. Job Level vs Attrition

## Key Insights

The visualizations help identify patterns and relationships in employee attrition data.

The analysis focuses on factors such as department, gender, age, income, job satisfaction, overtime, and job level that can help understand employee attrition.
